# Agent Control Specification (ACS) — runtime guardrails

**Agent Control Specification** is the OSS solution for AI agents runtime control. It enforces deterministic, policy-driven guardrails on every agent turn: input filtering, LLM calls, tool calls, and output redaction. Same policy setup works against all your and the policy becomes a runtime contract the agent cannot bypass.
