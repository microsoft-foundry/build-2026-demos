## Build 2026 Foundry IQ Announcements

* **Foundry IQ is generally available.** The all-in-one RAG (Retrieval-Augmented Generation) engine for agents — knowledge bases, multi-source agentic retrieval, planner activity, and answer synthesis — graduates to GA and is fully integrated with Microsoft Foundry Agent Service so agents stay on task across every knowledge source you connect.
* **Work IQ knowledge source integration.** Bring Microsoft 365 work context — Teams, Outlook, OneDrive, SharePoint — into your knowledge base through the new Work IQ integration, with Microsoft Entra-aware retrieval out of the box.
* **Fabric IQ knowledge source integration.** Ground agents in your enterprise data estate by pointing a knowledge source at a Microsoft Fabric ontology. Agentic retrieval runs against the same governed semantic model that powers your BI, with no copy of the data.
* **Foundry IQ in Microsoft Copilot Studio.** Citizen developers can now select a Foundry IQ knowledge base directly inside Copilot Studio as a grounding source for their copilots — same retrieval quality as code-first agents, zero code.
* **Microsoft Purview + ACL trimming for knowledge sources.** Document-level access control is enforced end-to-end: knowledge sources honor source-system ACLs and Purview sensitivity labels at query time, so an agent only ever returns content the calling user is entitled to see.
* **Serverless SKU in preview.** A new pay-as-you-go tier for Azure AI Search lets you stand up Foundry IQ knowledge bases without provisioning capacity — ideal for prototypes, bursty workloads, and ISVs embedding Foundry IQ into their products.
* **Three new knowledge source types in preview.** Connect a knowledge base to **Local Files** (laptop / dev box content), to a remote **MCP** server, or to a **SQL** database — each ships with the same agentic retrieval engine, citations, and Purview/ACL trimming as the GA sources.
